Wholesaler feed → catalog.js

Converts a supplier product feed (CSV or XML) into the CATALOG array this shop uses.

Built blind, on purpose. Erotizo's actual feed format was not reachable when this was written, so nothing here assumes their column names. Load their file, map the columns once, and the mapping is remembered. If their feed is an API rather than a file, send me the endpoint docs and this becomes a fetch instead of an upload.
